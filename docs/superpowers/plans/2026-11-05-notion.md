# Notion Implementation Plan

> **For agentic workers:** execute task by task (superpowers:executing-plans). Checkbox steps.

**Goal:** Aba "Notion" no admin: árvore de páginas, editor de blocos com `/`, colar link (link/anotação/embed), hub com botões para Biblioteca, Referências e Mapa mental.

**Architecture:** Tabela `notion_pages` (parent_id, content jsonb). Server actions com `requireTeam("notion")` → `lib/notion.ts` (Supabase service role). Editor BlockNote (mantine, MPL) em client component carregado com `dynamic(ssr:false)`. Blocos custom: `bookmark` e `embed`.

**Tech Stack:** Next 16.3, React 19, Supabase, BlockNote 0.57 (`@blocknote/core|react|mantine`), vitest.

**Spec:** docs/superpowers/specs/2026-11-05-notion-design.md

## Global Constraints
- Seção de acesso `notion` (href `/admin/notion`); nada de editar `proxy.ts`.
- Não tocar `backlog_cards`, Biblioteca, Referências, Mapa mental.
- Migrations: `0104_notion_pages.sql`, RLS ligada sem policy. Só rodar em produção com autorização do Vitor.
- Branch `notion`; não commitar até o Vitor dizer que está 100%.
- Só pacotes MPL do BlockNote (sem `@blocknote/xl-*`).

## Review Focus
- Salvar com `updated_at` mais novo no banco → recusa e avisa (sem sobrescrever).
- Mover página para dentro de descendente → bloqueado.
- Arquivar página arquiva subárvore; restaurar traz junto.
- URL colada inválida/sem https → vira link simples, sem quebrar.
- Site que bloqueia iframe → embed vira anotação.
